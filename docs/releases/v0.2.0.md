# Code Flow Studio 0.2.0

By Jason Stys — [GitHub](https://github.com/JasonStys), [contact](https://www.linkedin.com/in/jason-stys-31b30b351/).

Real local accounts, independent vault phrases, encrypted locked source/history/API settings, per-session key proof, login recovery, safe account deletion, contextual help and token-free local browser access. Offline editor, static review and saved revisions work without Docker. Explicit own-provider routing/consent supports compatible OpenAI, Anthropic and Ollama APIs; model proposals remain unverified until independently tested.

OS packages: Windows x64 per-user NSIS installer/portable ZIP, macOS ARM64 DMG/archive and Linux x64 AppImage/archive, each with SHA-256 checksum and bundled third-party notices. The complete extracted portable directory is required. No Python/Node/IntelliJ setup for end users.

Packages are unsigned, not notarized or independently certified. No public backend/mobile native installer is provided. Actual compiler jobs require the reviewed local Docker image; no host fallback or Docker repair occurs. Training is a separate optional workflow. Active source/memory is plaintext accessible to the local OS/admin; locked encryption is not zero-knowledge hosting. Save revisions before lock. Cold-back up the entire private root, not only its encrypted archive. Read the installation, recovery and security documentation before use.
