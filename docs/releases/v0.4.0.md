# Code Flow Studio 0.4.0 — verified source review

By Jason Stys. Adds a complete developer triage workflow across diagnostic, unused-code and
missed-coverage references, while retaining private local accounts and isolated workers.

- Filter by file/category, inspect the exact read-only source snapshot, browse physical lines,
  and open the editable draft only if its original-byte SHA-256 still matches. Generated tests
  and harnesses remain separate from supplied source; stale drafts are never overwritten.
- A native read-only inspector avoids another editor/model/worker lifecycle. The editable
  Monaco integration retains rapid typed input correctly. Legacy, binary, missing-source,
  hash-mismatch and out-of-range references have honest unavailable states.
- Explicit Clang19/compiler-rt/symbolizer for libFuzzer, bounded same-container old/new startup
  comparison and a deliberate ASan fault control. ASLR, sanitizers and all container limits remain.
- Separate worker analyzer dependency audit, tested minimatch patch and independent exact-line
  JS/TS fixtures. Pinned Electron44.10.2 is installed and verified before timed native journeys.
- Private provider consent, account encryption, immutable approved oracles and no host-execution
  fallback remain. No account, history, vault or database schema migration is introduced.

**Worker update required:** on an already working authorized local Docker engine, build
`docker build -t code-flow-worker:0.4.0 runner`. The new tag prevents an older installed runtime
from being mistaken for this release's worker. Missing isolation remains blocked; source/static
review, help and encrypted history remain usable. Docker is never automatically repaired.

Read [source navigation](../source-navigation.md), [worker compatibility](../worker-toolchain.md)
and [observed validation](../reports/practical-workflows-2026-11-09.md). The publication workflow
requires exact-source validation/package success before releasing assets. Local results do not
substitute for those gates. Packages remain unsigned development builds; no universal bug-finding,
formal coverage, public hostile-code SaaS or useful general coding-model claim is made.

Existing release tags/assets remain intact. Close the app before changing installed versions,
retain a separately verified encrypted backup, and use the previous release/its matching worker
for rollback. Histories are immutable evidence and are not recalculated automatically. This
release does not import old plaintext projects or change users' provider settings.
