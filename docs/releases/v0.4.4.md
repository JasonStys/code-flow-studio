# Code Flow Studio 0.4.4 — reviewed desktop runtimes

By Jason Stys. This maintenance release retains the 0.4.3 C# coverage correction,
exact source locations, unused-code checks and isolated compiler workflows. It
updates the desktop service to Python 3.14.10 and the shell to Electron 44.11.0.
Frozen services refuse a different Python build before opening private account
storage; health and native acceptance report the interpreter actually running.
Source development continues to support the Python versions in `pyproject.toml`.

The worker remains on its separately tested Python 3.12 compatibility line and
uses the Python 3.12.16 Bookworm image pinned by digest. Product and worker-image
identities advance together to 0.4.4. Build the matching worker in a supported
isolated environment; compilation remains blocked when that worker is unavailable.
There is no host-execution fallback. Docker on the development PC is unchanged.

Account and encrypted-history formats do not change. Quit the existing app cleanly
and back up its private data before upgrading. The installer preserves data outside
the installation directory and retains the existing application identity. Package
checks, source checks and independently downloaded installer acceptance must pass
before publication. Packages remain unsigned; no signing or notarization is claimed.

Python 3.14.10 is the expedited security release described in the
[official release notice](https://www.python.org/downloads/release/python-31410/).
Historical 0.4.3 compiler measurements and installer reports remain dated evidence,
not measurements of this release. The current validation report records exact
source commits, actual runtime versions, results and remaining environment limits.
