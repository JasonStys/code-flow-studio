# Code Flow Studio 0.3.0 — polyglot source evidence

By Jason Stys. Adds native coverage and exact unused-code locations across all eleven non-Python execution adapters, in addition to existing Python support.

- Original file/line/column, rule and source hashes for native unused candidates, with controller path/range/hash binding.
- Real language-specific coverage: V8/TypeScript maps, GCC, Rust/LLVM, JaCoCo, Coverlet, Xdebug, Bash command entries, SQLite statement starts and assembly DWARF/Callgrind.
- UI and escaped HTML expose tool/metric, partial/blocked/unknown states, missing source lines and native branch counts/IDs without inventing destination arcs.
- Fixed, pinned/audited tools run inside the existing restricted worker, separate from baseline timing/RSS. Independently authored positive/negative location oracles cover every adapter.
- No account/history migration, automatic source changes or user-data collection. Public providers remain opt-in; downloaded applications remain unsigned development builds.

**Worker update required:** build `code-flow-worker:0.2.0` from this release's `runner` directory on an already working authorized Docker engine. Missing isolation stays blocked; the app neither repairs Docker nor executes targets on the host. These are bounded flat CLI adapters, not universal frameworks or public hostile-code sandbox support.

Read [polyglot evidence](../polyglot-locations.md), [validation](../validation-polyglot.md), [security](../security.md) and [private operation](../private-accounts.md). Roll back by reinstalling the prior release and restoring a separately verified encrypted backup if needed; no database migration is introduced. Do not downgrade while an app instance is open. Existing histories remain revision-bound and are not recalculated automatically.
